# Perfil local — capivara

> Copie para `perfil-local.md` e responda. O `ADAPTAR.md` faz isso com você.

## 1 · Onde o relatório é salvo

```
destino:
```

Exemplos: `~/notas/pessoas/`, `~/vault/Atlas/People/`, `./capivara/` (padrão), ou
`nenhum — só mostrar na conversa`.

## 2 · Como o arquivo se chama

```
padrao_de_nome:
```

Padrão: `<nome-em-minúsculas>-<AAAA-MM-DD>.md`. Uma pasta por pessoa, com o relatório dentro,
também é comum.
