# DNA checklist — pass de revisão aplicável

Checklist genérico baseado no `DNA.md` raiz. Usado por todo modo de polish (`modes/newsletter.md` etapa 4a, `modes/post.md`, `modes/longform.md`). Cada modo pode complementar com itens específicos.

## Pass DNA — voz

- [ ] **Primeira pessoa, narração:** soa como Flavio falando para um amigo, não palestrando.
- [ ] **Frases curtas predominam.** Sem rodeios antes de chegar ao ponto.
- [ ] **Sem rebuscamento:** palavras simples, germânicas, curtas.
- [ ] **Sem tom de coach:** a experiência fala, não o autor.

## Pass DNA — estrutura

- [ ] **Ganchos curtos:** primeiras 1-2 frases funcionam sozinhas.
- [ ] **Parágrafos de 2-5 frases** (longform pode ir até 7 onde a ideia exige).
- [ ] **Uma ideia por parágrafo.**
- [ ] **Transições naturais** sem "além disso", "nesse sentido", "por outro lado".
- [ ] **Bullets só em listas operacionais** (passos, comparações, especificações). Não no corpo narrativo.
- [ ] **Fechamento sem moral** — sem CTA inspiracional, lição de vida, pergunta condicional.

## Pass DNA — linguagem

- [ ] **Sem maiúscula após dois-pontos.**
- [ ] **Sem absolutos não embasados** ("sempre", "nunca", "todo mundo") sem evidência.
- [ ] **Sem hipérboles** ("mudou tudo", "outra categoria", "revolucionário").
- [ ] **Números concretos** preferíveis a generalidades ("31 canceladas, 6 movidas").
- [ ] **PT-BR consistente:** IA (não AI), e-mail, software no português padrão.

## Pass DNA — proibições absolutas (temperatura zero)

- [ ] Não inventou pergunta retórica?
- [ ] Não fabricou diálogo / quote?
- [ ] Não criou estatística sem fonte?
- [ ] Não adicionou emoji no corpo?
- [ ] Não usou "nós" genérico?
- [ ] Não projetou sentimento no leitor?
- [ ] Não usou condicional inspiracional?
- [ ] Toda expressão sugerida pelo AI marcada `[SUGESTÃO AI]` ou removida?

## Pass DNA — voz autoral (humanizer §soul)

- [ ] **Tem opinião?** Não é só relato neutro de fatos.
- [ ] **Varia ritmo?** Mistura frases curtas e longas.
- [ ] **Reconhece complexidade?** Não força conclusão limpa onde a realidade é mista.
- [ ] **Usa "eu" quando faz sentido?** Primeira pessoa quando é experiência pessoal.
- [ ] **Específico sobre sentimento?** Não "preocupante" mas "tem algo desconfortável em..."

## Output do pass

Para cada item marcado fora do checklist, propor edit cirúrgico (não reescrita de parágrafo). Se um parágrafo precisar de reescrita, sinalizar — não reescrever sem aprovação.

Anotar:
- Quantos itens passaram (ex: "32/36 OK").
- Quais falharam e onde (frase / parágrafo).
- Qual edit proposto.
- Qualquer dúvida que pede decisão de Flavio (ex: "esse 'nós' é genérico ou está se referindo à equipe Mondoré?").
