# Examples — seus textos de calibração

Esta pasta guarda (ou aponta para) **os seus** textos publicados. A skill lê 2 a 3 antes de
escrever prosa, para calibrar voz. Começa vazia de propósito.

## Como montar

1. Escolha textos **seus, já publicados**, do canal para o qual você vai escrever.
2. Ponha o arquivo aqui, ou uma linha com o link se o texto vive online.
3. Anote numa frase **o que aquele exemplo demonstra** — "abertura com fato e número",
   "fechamento em 3 tempos", "tom conversacional sem listas". É isso que torna o exemplo útil;
   uma lista de links não calibra nada.

| | | |

## Limites

- **~12 por canal.** Mais que isso e a skill escreve em "voz média" diluída.
- **Nada com mais de 6 meses** como calibração principal — voz evolui.
- **Mínimo 2.** Calibrar por um texto só captura idiossincrasia, não voz.
