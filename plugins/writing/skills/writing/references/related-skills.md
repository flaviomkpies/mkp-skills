# Skills relacionadas

A skill `/writing` cobre a **criação** de texto. Duas coisas ficam de fora dela por natureza:

- **Resumir um artigo de outra pessoa** — é sumarização de input externo, não criação editorial.
- **Publicar** — depende da conta e do canal. A skill entrega o texto final; a publicação é sua.
